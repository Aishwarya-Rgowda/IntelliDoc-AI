Quick guide: file types & sizes

New to PDF, PNG or MB? Here is what these words mean.

📄 PDF

Portable Document Format. Keeps a document's page layout consistent when opened on different devices.

🖼️ PNG

Portable Network Graphics. An image format that supports transparent backgrounds; useful for logos and graphics.

📷 JPG / JPEG

A common photo format. It usually creates smaller files than PNG, but uses lossy compression.

📝 DOCX

A Microsoft Word document format that you can edit in Word and compatible apps.

📦 KB & MB

These measure file size. 1 MB is about 1,000 KB (or 1,024 KB in computer storage calculations). More MB means a larger file.

✂ Split / Merge

Split: separate selected pages into a new PDF. Merge: join multiple PDFs into one.

📏 What is the file-size limit?

The converter tools do not have one fixed MB limit set here. The size you can process depends on your browser, device memory and the PDF/image itself. Very large files may be slow or fail. Files are processed in your browser.

🔒 Private by design

Your files are processed locally in this browser and are not uploaded to IntelliDoc servers. PDF operations require the free PDF library to load from the internet. Large files may take longer depending on your device.
